# Tomain — Central de Agentes

Ambiente único onde os agentes da Tomain Engenharia são definidos, orquestrados e auditados.

- `CLAUDE.md` — regras que valem para todos os agentes.
- `docs/ARQUITETURA.md` — como as peças se conectam.
- `docs/ACESSOS.md` — níveis de acesso e o que cada agente pode fazer.
- `agentes/` — um arquivo de escopo por agente (orquestrador, propostas, comercial, jurídico, marketing, assistência técnica, financeiro, melhoria de sistema, qualidade).
- `docs/GERADOR-EM-PARALELO.md` — como integrar sem risco para o gerador que já funciona.
- `docs/TERMINAIS-FUNCIONARIOS.md` — entrada de dados por outras pessoas, com login e papéis.
- `docs/CONTAINER.md` — onde e como o projeto roda.
- `testes/` — bateria de casos do agente Qualidade.
- `docs/ROADMAP.md` — do modo "tudo sob pedido" até a automação gradual.
